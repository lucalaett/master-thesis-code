# Master Thesis Code

Code and analysis notebooks for my master's thesis.

## Repository structure

* `chains/` – output timing residual chains
* `data/` – EPTA data of TOAs and model parameters
* `figures/` – exported figures used in the thesis
* `notebooks/` – Jupyter notebooks used for analysis and figure generation
* `src/thesis/` – reusable Python functions for analysis and plotting

## Usage

Install the required Python packages, then open the notebooks in the `notebooks/` directory and run the analysis cells to reproduce the figures.
